LLMs bring the change

Younger members of my team use ChatGPT liberally when coding. No task is too difficult for them.

I am unsure about how to feel about this. On the one hand, I know that work is getting done quickly. Bugs are fixed. Code is of acceptable quality.

On the other hand no thought goes into coding. It’s just a question to ChatGPT: here’s the requirement. Here’s the code. Here’s the error. Fix it. And it’s fixed.

Will they be able to design a system? Perhaps - if ChatGPT helps them. Can they reason about their design decisions? Maybe not that well.

The days where we had to ’learn’ programming are gone. What’s the point of learning syntax? You can pose a question to an LLM to get the code, test it, feed the error back into the LLM until everything works. You will be no wiser, but the work will get done with minimal stress. The joy of solving a coding challenge will be less sweet knowing that an LLM freely available would be able to do it much faster and with better quality.

In one of my projects, a mediocre programmer, using ChatGPT and feeding it the WRONG prompts, came up with incorrect code that failed in spectacular fashion. This was because he didn’t understand that code that didn’t throw a runtime error was not the only parameter for correctness. He had to think about the intention behind the code, but in his laziness and urgency to get things done he wrote code that just “worked” for him but not for other cases.

I fear that coding will cease to be an art. I mean - LLMs can produce art and can produce “artful” code, but the aspect of appreciation of the coder’s ingenuity will be lost. I used to write firmware code for Secure Digital readers where the firmware had to respond as quickly as possible so that we had good results in benchmarks. On one occasion I wrote assembly code to make something in the critical path faster by 5x and I was proud of it. I don’t know if I would feel that way any more.

I fear that managers will be have higher expectations on productivity and timelines and effort estimates will shrink. The impact of LLMs on coder productivity are unquantified, so this just seems like baseless fear at this point: but if adoption of LLMs begins to be widespread and we start seeing code bases created faster and with better quality, we will begin automatically to have higher expectations from ourselves.

I fear that LLMs will be an irreplaceable tool for software engineers. The old-school way of reading documentation to do things the right way will be so severely hampered that it wouldn’t make sense to even account for “RTFM”.

People say that we shouldn’t be afraid of LLMs, and I agree. Books, computers, the internet, cars - all these were feared as being detrimental to society and they weren’t. We adapted and sought higher goals. Perhaps LLMs will free us, not from work, but to chase bigger things. Yet I have used the words “I fear” thrice because I am afraid of change.
